## 2. 为什么 v2 能比 v1 提升 3.82 分？（因果复盘）

v1 与 v2 的主模型（Qwen3.8-Flash-Next W4A16）、推理运行时（Pennyroyal SGLang）及视觉感知均完全一致，提升完全来自**外循环算力调度逻辑的纠偏**：

1. **彻底拆除 2,000,000 新游戏强制门禁（`install_d`）**：
   - v1 最大的失误是保留了 Franzen 的 `Gate.acquire` 200 万优先级硬门禁，导致无论正在求解的游戏多么接近深层通关，一旦有新游戏到达就会被强行剥夺 GPU 槽位。
   - v2 采用 `install_d`，新游戏在 `Gate.acquire` 处统一使用 $D'$ 初始期望快照（$\ell=1, a=0, t=0$）平滑排队入队，保证了高价值活跃游戏的连贯推进。
2. **动态 Pace 速度自适应（`FormPace`）**：
   - 依据各游戏历史过关实际平均消耗的 Token，在 $[0.25, 4.0]$ 倍率区间内动态缩放。过关迅速的游戏获得更多算力倾斜，迟缓卡顿的游戏自动降权。
3. **尾部时间衰减收割（Tail Fade）**：
   - 在 9 小时比赛最后 40% 时间窗口内（$\phi \to 0$），剩余关卡期权收益平滑归零，调度器停止在深层新局上盲目铺摊子，全力收割当前正在手头的关卡。

## 4. 距离 35+ 分梯队的四大核心差距分析

调度公式解决了“**算力如何分给正确的游戏**”，但要迈进 35+ 分，瓶颈在于“**进入槽位后，Agent 每一关的动作浪费**”：

### 差距一：死循环动作损耗与 RHAE 平方惩罚
* **评分机制**：$\text{Score} = 100 \times \left(\frac{\text{Human}}{\text{Agent}}\right)^2$。
* **物理事实**：
  - 当 Agent 理解规则时，步数仅为人类的 0.71 倍（RHAE > 100 分）；
  - 但 Agent **62% 的全场动作**都浪费在它从头到尾都没理解的那一关上。连续 30~50 步原地打转或撞墙，会直接把该关得分摧毁至个位数或 0 分。
* **高分方案做法**：
  - 取得 **36.98 分** 的 Lord Han Solo 方案引入了 **`Strategy-Audit` 强制超时重审**：单关耗费 25% 预算或连续多次无有效状态改变时，Harness 强行介入打断模型当前偏执的假设，提示模型使用 `UNDO` 或回退。
  - v2 目前尚未激活该反思机制，陷入死循环时依然在机械耗尽步数。

### 差距二：59k 激进历史裁剪导致的“跨关失忆”
* **深层关卡是得分重心**：Level 7~10 的通关权重远高于 Level 1。
* **当前系统缺陷**：
  - Franzen 基线在上下文达到 118k 时，直接粗暴丢弃最早的 59k 历史。
  - 这导致 Agent 在 Level 1~3 好不容易摸索出的物理规律（如特定颜色属性、特定按键功能）被完全遗忘，进入深层关卡时又退化为从零摸索。
* **高分方案做法**：
  - sirikilohit（M2 获奖方案）引入了 **`Solved-Level Episodic Memory`**：每通关一关，将上一关发现的物理法则与**最后 30 步通关动作序列**直接钉在 System Prompt 顶部，免疫 59k 上下文裁剪，深层关卡秒级复用经验。

### 差距三：批量动作撞墙的无谓浪费（No-op Batch Waste）
* **当前缺陷**：
  - Agent 在一次 Python 工具调用中往往一次性下发 10~20 步动作。如果第 1 步就撞墙或者卡住，棋盘根本没动（`gameplay_changed == False`），但后续的动作依然会被计入动作总数，直接增大分母。
* **高分方案做法**：
  - 强化 **No-op Batch Stop** 守卫：一旦监测到动作对关卡内部产生零影响，立刻熔断该批次，退回给模型重新规划。

### 差距四：单次采样的自然方差
* 论坛审计贴（Topic 745062）对同一套 D′ 代码的 100 次 Trajectory 审计显示：**均值为 25.77，标准差为 3.93**（同一代码最低 21.0，最高 31.9）。
* 28.04 属于均值偏上的扎实得分，但要稳定突破 35+ 分，必须通过认知守卫将系统下限拉高。

## 5. V3 升级攻坚计划（冲刺 33 ~ 37+ 分）

1. **安全接入 `StrategyAudit`（策略审计）**：
   - 补齐形参完整签名（`*args, **kwargs`），在单关动作 $\ge 24$ 步仍未通关时注入反思警示，引导模型使用 `UNDO` 与切换假设。
2. **实现 `SolvedLevelMemory`（通关记忆置顶）**：
   - 将已通关 Level 的关键物理规律和有效动作序列置顶在 System Prompt，杜绝 59k 裁剪失忆。
3. **强化 `NoopRepeatGuard`（无效动作熔断）**：
   - 连续撞墙/无效动作秒停，保护平方分母不膨胀。
